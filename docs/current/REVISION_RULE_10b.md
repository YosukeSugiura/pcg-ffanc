## 1. 訂正: w-excess の理論参照
- 10a の参照 w_LS は、w_b と同じデータを含む全区間 LS（n_h hop）である。このため E‖w_b−w_LS‖²_R ≈ E‖w_b−w_o‖²_R − σ²M/(H n_h) となり、比べるべき理論値は σ²M/(Hb) ではなく **σ²(M/H)(1/b − 1/n_h)** である（internal code review で合成データを確認。exact LS での理論のずれは、5 s・100–312 で −3.93 dB、20 s・625–1250 で −5.54 dB）。
- 比 = 10log10(アンサンブル平均 w-excess の区間平均 / σ²(M/H)(1/b − 1/n_h) の区間平均)。n_h はその実行の hop 数（5 s: 312、20 s: 1250）。自由パラメータはない。
- slope: 参照の偏りを足し戻した量 w-excess + σ²M/(H n_h)（≈ E‖w_b−w_o‖²_R）の log を log b（b＝更新回数、ew の添字）に回帰する。1e-12 以下の hop は除く。
